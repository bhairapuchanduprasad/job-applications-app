# Project brief: Semantic Layer & Metrics Agent (KoRo Analytics Engineer CV)
Goal: small analytics-engineering repo: dbt models + semantic layer + AI analysis agent with eval. Reuses the planned "Semantic Analytics Agent" idea.
Proves: dbt, SQL, data modeling, automated testing, data dictionary, semantic layer, evaluating AI-generated answers.
Scope (1-2 days): synthetic e-commerce data (orders, products, customers) in Postgres (DuckDB/BigQuery sandbox optional); dbt staging + mart models with tests (unique, not null, relationships); metrics defined once (dbt metrics/MetricFlow or YAML); versioned data dictionary (dbt docs); LangGraph agent answering only via approved metrics; eval set of 20 business questions with known answers, report of mismatches.
Milestones: 1 data + dbt models/tests; 2 metrics + dictionary; 3 agent; 4 eval + README.
README: architecture diagram, how to run, eval results (real only), demo GIF.
CV bullets to live up to: dbt staging/mart models, automated tests, versioned data dictionary; business metrics defined once in a semantic layer; agent answers only through them; evaluation set exposes modeling gaps.
