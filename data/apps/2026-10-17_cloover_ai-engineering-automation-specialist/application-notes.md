## Likely interview questions
1. **"Pick one Ops workflow and tell us how you'd automate it."**
   Start from volume and pain (ask which tickets/tasks repeat most). Example: installers asking about financing or order status → read-only MCP tools over HubSpot + SOP retrieval from Notion → draft answer in Slack with sources → human sends → measure share answered, time saved, error rate → only then let it act on its own.
2. **"How do you know an agent is good enough to trust?"**
   Ground truth and numbers: Kniit P/R 33%/45% → 93%/90% against SAP data; reflection agent; human approval in Expert Interface; RAGAS at Covestro. Rule-based or deterministic where an LLM isn't needed (the $200k example, told neutrally: "the second source stream got a deterministic pipeline").
3. **"How would you get non-technical colleagues to keep using AI workflows?"**
   Build where they already work (Slack, HubSpot), keep a human in the loop at first, short onboarding guide, Claude Code skills that encode the team's steps, watch usage and fix what they skip. Point to Expert Interface (domain experts approving graph changes themselves).
