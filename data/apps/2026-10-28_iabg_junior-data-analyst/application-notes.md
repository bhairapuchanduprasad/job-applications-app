# Application notes: IABG, (Junior) Data Analyst militärische Luftfahrzeuge

## Likely interview questions (expect German)
1. **Wie gehen Sie mit unvollständigen, inkonsistenten Datenlieferungen um?** Sichtung → Typen/Einheiten/IDs prüfen → Regeln dokumentieren → Datenqualitätsbericht; Beispiel Covestro-Sensordaten (Lag-Features, gleitende Fenster), Kniit (Ground-Truth-Abgleich).
2. **Warum Verteidigung / Waffensystemdaten?** Your own answer needed (fit report: decision for you). Also expect questions on a security check (Sicherheitsüberprüfung) as a non-German citizen.
3. **Wie stellen Sie Codequalität sicher?** Clean code, Git, GitLab CI/CD; code reviews only via the project once built.

## Form fields
- **Warum IABG:** analysis of operating, sensor and logistics data of complex technical systems; structured onboarding into the data landscape.
- **Gehalt:** €60,000–65,000 for a junior title (single number: €65,000 suggested; profile default €70,000).
- **Eintritt:** 15.11.2026. **Standort:** Dresden (relocation).
- **Deutsch:** B1, no certificate. **Staatsangehörigkeit / Sicherheitsüberprüfung:** answer truthfully; may be a blocker.
