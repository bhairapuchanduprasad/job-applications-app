**2. "How would you help our developers work more efficiently with GenAI?"**

Your evidence: Claude Code with custom skills at Kniit, MCP server built for Claude Code. If the Spec-Driven Coding Agent Harness is built by then, demo it.

Also prepare: "Do you know Java?" → honest: Python is your main language; you haven't built in Java. "Why did you leave Kniit?" → public line from profile. Expect part of the interview in German; B1, be upfront.
