Job Description

About the Role:  

We are seeking a MLOps Engineer (m/f/d) to build, operate, and improve ML/AI solutions in production. You will work at the intersection of data science and software engineering, helping to turn models into secure, maintainable, and reliable production services. You’ll collaborate with data scientists and engineers in cross-functional product teams and contribute to the continuous improvement of our MLOps practices and platform.

Tech stack: Python, Docker, Kubernetes, GitHub Actions, Jenkins, MLflow, Kubeflow, CI/CD, Git/version control, automated testing, model packaging and versioning, model validation and monitoring, observability, and secure software development/DevOps practices.

About your tasks:

- Build and operate containerized services using orchestration platforms such as Kubernetes. 
- Troubleshoot production issues and improve the reliability, performance, and cost-efficiency of ML/AI services. 
- Develop maintainable and well-tested Python code for production services, automation, and internal tooling. 
- Build and improve CI/CD pipelines for ML/AI services, enabling reliable testing, deployment, and model iteration. 
- Implement data and model versioning, validation, and observability to support integrity and reproducibility throughout the ML lifecycle. 
- Contribute to technical designs and architecture decisions, and participate in code reviews. 
- Integrate automated security checks into delivery pipelines and follow secure development and operations practices. 

Qualifications

About you:

- Practical experience in MLOps, DevOps, platform engineering, or software engineering, including deploying and operating ML/AI solutions in production. 
- Solid software engineering skills in Python, including automated testing, version control, and code review. 
- Hands-on experience with Docker and container orchestration platforms such as Kubernetes. 
- Experience with CI/CD tools such as GitHub Actions or Jenkins. 
- Familiarity with ML lifecycle practices such as model packaging, versioning, validation, deployment, and monitoring; experience with tools such as MLflow or Kubeflow is welcome. 
- A solid understanding of software architecture and secure software development and delivery practices.
